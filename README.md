# 主動式 ETF 雷達

GitHub Pages 版的主動式 ETF 持股追蹤網站。

## 報酬率計算

每個持股週期會依持股異動紀錄計算：

- 首次納入與每次加碼：以當日張數及當日收盤價計入買進成本。
- 減碼與出清：以當日收盤價計入賣出收入。
- 尚未出清部位：以股價快取中的最新收盤價估值。

因此顯示的是已實現與未實現損益合併後的近似實際報酬率，而非「首次納入日價格」的單點比較。交易資料為 ETF 持倉的日終揭露，並不代表基金實際成交價。

股價快取不會在首頁預先下載；僅在開啟個股明細或最大漲幅排行時才按需載入，以縮短首頁載入時間。
